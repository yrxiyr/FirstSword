# The FirstMod

Minecraft **1.21.1** + **NeoForge 21.1.x** 的模组，加了一把叫「初锋」的剑。

## 内容

### 初锋 `chufeng:first_sword`

- 钻石级剑，面板攻击力 **14**，攻速 -2.2
- 合成：2 钻石 + 1 木棍
- **耐久无限**，永远不会损坏
- **死亡不掉落**：死亡时自动收好，重生后回到背包（词条和附魔都保留）
- 支持词条：装上附属模组「更强的初锋」后可以往剑上打核心

### 攻击一：彩虹雷电（右键）

以自身为中心、半径 30 格内落下 **3 波 × 36 道**彩虹闪电。

- 每道造成 **15 点伤害** + 击退
- 只对敌对生物生效
- 同一目标每次释放最多吃一次伤害
- 冷却 1.5 秒

### 攻击二：流星群（长按 J）

蓄力 0.4~3 秒后松手释放：

- **大流星**：落在准星指到的位置（32 格射线），**96 点伤害**，
  冲击波半径 **18 格**（是砸坑半径的两倍，一直推到小流星的散布区外沿），
  砸出半径 9 的坑，坑底起伏 4~5 层，约 60% 的地表铺火
- **小流星**：围绕大流星落点 18 格内散开，数量随蓄力 **24 → 96 颗**，
  每颗 8 点伤害，砸出半径 2 的小坑
- 所有流星（含大流星）都以 **45° 夹角**斜插下来，同一场雨共用一个方位角，
  看上去是平行的一整片，而不是一根根垂直的柱子
- **空中法阵**：准星前方 50 格、50 格高的空中会张开一个半径 24 格的彩虹法阵
  （外圈粗环 + 内圈细环 + 24 根辐条 + 六芒星，缓缓反向旋转，色相流动）。
  所有流星都在法阵所在的平面上出生，看起来是从法阵里飞出来的
- 小流星先在约 2 秒内陆续落下，**大流星压轴**
- 蓄力超过 35% 时整屏颜色反转
- 冷却 32 秒

### 攻击三：瞬闪斩（K）

按下 K，朝准星方向**冲刺 8 格**（0.1 秒），路径上的敌人被一并切开。

- 路径伤害 **30 点** + 击退，判定半径 2.4 格
- 落点再补一刀 **20 点**，半径 3.5 格
- 同一次斩击里每个目标最多吃一次
- 只打敌对生物，不会伤到队友和宠物
- 冲刺是**速度推进**而不是瞬移，镜头连续移动；可以从怪堆里穿过去，被方块挡住会停下
- 遇到一格高的台阶会自动抬上去继续
- **砍到怪会刹车**：一刀没秒掉的（还站着）速度直接掉到 15%；能秒掉的怪不减速
- **整条冲刺路径铺满彩虹刀光**：沿路每 0.8 格一道月牙，收刀时在落点再炸开一圈（8 道），
  朝向完全随机，0.4 秒内淡出；沿途还有彩色粒子斩痕
- 冷却 8 秒，冷却中会在动作栏提示剩余秒数

注意：位移的冷却**单独记**，不占物品冷却，所以放完流星也能立刻闪走。

按键可在「选项 → 控制 → The FirstMod」里修改。

## 安装

1. 安装 Minecraft 1.21.1 与 NeoForge 21.1.x
2. 把 `chufeng-1.6.0.jar` 放进该版本的 `mods` 文件夹

## 从源码构建

需要 **JDK 21**。

```bash
./gradlew build
```

产物在 `build/libs/`。开发时可直接运行 `./gradlew runClient` 启动带模组的客户端。
